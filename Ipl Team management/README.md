# IPL Player REST API

## Technologies
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- REST API
- Postman
- Maven

## Features
- Add Player
- Get all Players
- Get Batsmen
- Get Bowlers
- Get Player by ID
- Get Players by Team
- Highest Score
- Highest Wickets
- Update Score
- Update Wickets
- Update Team
- Delete Player
- Delete Players by Team
- Top 3 Players
- All-Rounders
